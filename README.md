# Fernando Andrade · Productor Multimedia

Portafolio web de Fernando Andrade, productor multimedia salvadoreño y estudiante de Ciencias de la Comunicación en la Universidad Don Bosco. Videos cortos, coberturas en tiempo real y contenido con inteligencia artificial para fintechs y startups digitales.

## Estructura

- `assets/js/data.js`: contenido de los casos de estudio, redes sociales y el ID del video de presentación.
- `assets/js/layout.js`: menú, pie de página y botón de WhatsApp compartidos por todas las páginas.
- `assets/js/anim.js`: animaciones (GSAP + ScrollTrigger).
- `assets/docs/`: PDFs descargables y las páginas de cada documento para el visor en línea.
- `assets/img/`: imágenes optimizadas de la marca y de los proyectos.

Sitio estático, sin dependencias de compilación: se publica tal cual con GitHub Pages.
